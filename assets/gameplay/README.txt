Every JSON and data file the app reads at runtime. menus/ holds title.json, mainMenu.json and backButton.json, which set the images, positions, animations and timing of the title screen, the main menu and the back button; menus/README.txt lists every key. scripts/PsychApiLibrary.hxc is the Psych Lua API written in HScript, embedded into converted V-Slice scripts, loaded with Platform.resourceBytes("gameplay/scripts/<name>"). introText.txt holds the title screen jokes, one per line, the two halves split by "--" like FNF's introText.txt.
